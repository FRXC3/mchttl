# What is mchttl?

mchttl is an advanced non-profit (vibe-coded) calculator project featuring the following calculation types:

### Player
- God mode
- Inf skill
- Inf burst
- Sprint CD

### World
- Auto dialog (max speed 1.5)
- Auto pickup

### Teleport
- Custom teleport route
- Nearest chest TP

### Visuals
- FPS unlock
- FOV unlock
- ESP (Types)
